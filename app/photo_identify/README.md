# 拍照识物：本地视频预览

两个应用的统一使用步骤、切换与排障见 [开发报告第 51 节](../../docs/bringup/official_lcd_feishu_report.md#51-两个原生应用使用手册2026-09-28)。

入口：桌面 → 应用中心 → 拍照识物。进入后后台初始化摄像头并持续采集，在 590×300 框中居中显示 480×270 RGB565。预览发布间隔至少 200 ms（目标约 5 FPS，实际帧率待真机测试），不经 PC、不编码 JPEG、不发送 USB 视频数据。初始化沿用完整传感器配置，可能需要数秒。

CSI 采用三块 1280×720 RGB565 缓冲，DMA 与读取者互斥持有完整帧；过期帧丢弃，仅发布最新预览。三块原始帧约 5.27 MiB，预览交换及显示约 506 KiB，不包含既有桌面、LCD 和跌倒监护缓冲。保留已验证传感器时序，未降低传感器输出帧率；使用 ISP 固定白平衡，不使用每帧软件 AWB。

返回应用中心即请求停止，当前初始化/缩放结束后释放摄像头。快速退出再进入时，旧任务未清理完会显示 Camera unavailable，稍后返回重进即可。跌倒监护尚在请求监控时拒绝启动预览；预览与 NSH 单帧采集共用互斥锁。无帧超过 3 秒报超时；停止或删除控制器失败时保留相关内存并要求复位，避免释放 DMA 所有的内存。

右侧提示区自动换行、可滚动。“拍照识别”按钮锁定当前显示帧，由独立 tools/photo_identify/identify_watch.py 读取并调用 PC AI，结果分段回传。等待期间保持锁定画面，结果完成后恢复预览；退出页面取消待处理请求。字库已扩充 GB2312 常用简体字符，罕见字符仍可能缺字。接口和运行方式见 tools/photo_identify/README.md。

验证状态：主机侧三缓冲（10000 次回调）与识物桥测试通过；真机端到端识别已完成（当前帧 → PC → MiMo → 中文结果分块回传并显示）。长时间连续预览、反复进出与内存余量尚未做统计。普通不含摄像头配置的桌面会显示 Camera not enabled。
